fizh

On-device neural machine translation in Zig, compiled to wasm32-freestanding. This page runs SPEC §13 T5: the §14 budgets on whatever device you opened it with.

Every number the project has published so far is a desktop proxy. The premise (invariant I1) is that Mozilla's engine is intgemm-based and x86-tuned while phones are ARM. The baseline / relaxed-SIMD comparison below is that premise, measured.
